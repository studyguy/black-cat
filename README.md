# 黑猫：墙中之声

一款改编自 Edgar Allan Poe 1843 年短篇小说《The Black Cat》的中文 2D 场景冒险原型。玩家扮演叙述者，在可点击的场景中行走、与物件和角色互动，并通过行动改变后续画面与结局。

> 当前版本是开发中的可玩原型，不是正式发行版。人物动画采用单张立绘的程序化纸偶分层；对话、部分场景演出、配乐与设备兼容仍有待完善。

## 运行

需要 Python 3 和支持 ES modules、Canvas 与 Web Audio 的现代浏览器；无需安装 Node 包或连接外部服务。

从仓库根目录启动本地静态服务器：

```bash
python -m http.server 8014 --directory build/app
```

在浏览器打开 <http://127.0.0.1:8014/>。也可以把 `build/app/` 部署到任意静态 HTTP 主机；不要直接用 `file://` 打开，因为游戏使用 JavaScript 模块和本地资源请求。

## 操作

- 在地面点击或触摸以移动叙述者；点击场景标记或底部动作按钮可走近并互动。
- 手机横屏优先，竖屏也可操作；桌面支持鼠标和方向键／A、D。
- 右上角按钮可切换声音或暂停。动画进行中可使用“跳过演出”。
- 游戏自动将当前场景、阶段和位置保存在浏览器本地；标题页提供继续与重新开始。

主流程包含家宅、花园与火灾、废墟、酒馆、地窖和警察搜查，并提供原著走向、沉默与自白三种结局。

## 开发与测试

此项目不使用 npm 依赖。使用 Node.js 运行规则和步态回归测试：

```bash
node build/app/tests/rules.test.mjs
node build/app/tests/locomotion.test.mjs
```

这些测试覆盖游戏状态迁移、结局门槛、存档恢复，以及步态的支撑脚、对称步幅、关节长度、停步与帧率稳定性。它们不是完整的端到端验收，也不能替代实际移动设备测试。

开发调试页面位于 `build/app/tests/gait-preview.html`，用于检查关节动作，不属于玩家入口。

## 素材与内容

场景底图及人物立绘使用本地 ComfyUI 生成或处理。游戏运行只需 `build/app/assets/` 下的运行时素材；生成工作流、原始输出和处理备份不随仓库发布。地窖场景使用无人物背景；素材生成过程中的中间稿不作为最终运行素材。

作品含有酗酒、动物伤害、火灾与死亡等主题；暴力以简短演出和文字克制呈现。游戏文案为本项目原创改写，不附带完整小说或外部中文译本。
